# Create Junior 交互原型

这是独立于生产页面的本地可点击原型，用来验证工作台布局、面板切换和设计状态流转。

直接打开 `index.html` 即可，也可以从仓库根目录运行：

```powershell
python -m http.server 8001 --directory prototype
```

原型内置的关键路径：

1. 参考资料工作台 → 生成结构候选。
2. 选择接合候选 → 查看问题和 AI 建议。
3. 确认设计 → 解锁加工包和 Airport 提交。
4. 底部命令栏输入自然语言或点击快捷建议。
5. 点击左侧问题、右侧面板和顶部导出，观察上下文切换。
6. 在中央视口尝试选择、卷尺、移动、旋转、缩放、镜像以及标准视图；中键旋转、右键平移、滚轮缩放会显示交互提示。

原型没有连接真实 AI、Airport 或项目存储，不代表最终视觉稿。
