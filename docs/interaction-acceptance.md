# 交互验收

2026-11-24 · 椅子范围编辑器与四步工作流

功能清单只能回答“有没有”，交互验收要回答四件事：

1. 用户能不能不看说明书完成一件事；
2. 动作有没有反馈，错误能不能恢复；
3. 预览、采用、撤销、检查、版本之间的状态是否一致；
4. 出错时系统是给可行动的下一步，还是把问题丢给用户。

## 两层验收

### 第一层：自动冒烟（每次改动都跑）

```bash
cd /Users/zhwei/Documents/dev/create-junior
.venv/bin/python scripts/verify_interaction.py
```

前置：本机服务在 `127.0.0.1:8000` 运行。脚本会创建两个临时项目，跑完手动清 `.data/workbench` 即可。

当前结果：**27 项通过**。覆盖：

- 打开编辑器、三维视口、对象树；
- 尺寸预览 → 取消 → 采用；
- 采用后版本递增；
- 撤销 / 重做；
- 拖拽移动进入预览（用程序化提交，验状态不验手感）；
- 孔位修改进入预览；
- 测量悬停实时距离、Esc 退出；
- 按需检查、覆盖边界；
- 开料 SVG；
- 无验证关联的尺寸修改会**拒绝并给可行动提示**，不写版本；
- 文档、生成加工包、PDF/ZIP 链接；
- 交付方式切换并写版本；
- 浏览器无脚本异常。

它不验：视觉层级、文案是否好懂、拖拽手感、真机、移动端、可访问性、真实加工店交付。

### 第二层：人工任务走查（每次交互改动都走）

10 分钟，按任务走，不按功能列表点。

#### A. 改尺寸（3 分钟）

1. 首页打开 CAFE CHAIR 样例，采用第一版，进入编辑器。
2. 点座板 → 属性里改宽 2 mm → “预览修改”。
3. 预期：模型只变预览，右上版本号不变；按钮变“采用修改”。
4. 取消 → 预期模型恢复，版本不变。
5. 再预览 → 采用 → 预期版本 +1。
6. 撤销 → 预期恢复；重做 → 预期再回来。

**失败信号**：预览直接改版本；取消后模型没恢复；撤销按钮灰着；采用后检查结果还显示旧版本。

#### B. 改位置和孔（2 分钟）

1. 选中座板 → 移动手柄拖 5–10 mm → 松开。
2. 预期：先出预览，不直接写版本；取消能恢复。
3. 旋转手柄转 2° → 松开 → 预览 → 取消。
4. 打开孔位折叠区，改一个 U 值 → 预览孔槽参数 → 取消。
5. 预期：孔位只进入预览，取消恢复。

**失败信号**：拖完直接保存；手柄和属性数值不一致；孔位改完没有提示连接检查会重跑。

#### C. 检查和出包（3 分钟）

1. 点“检查” → 预期有 blocker / warning / 未覆盖项，不是一句“通过”。
2. 点“开料” → 预期看到整板矩形排板、利用率和板幅。
3. 点“文档” → 预期有“生成当前版本加工包”。
4. 生成 → 预期出现 PDF / ZIP 链接；没有 blocker 才成功。
5. 在 PS 2026 参考模型上改尺寸 → 预期系统明确说“没有已验证的尺寸关联”，并**不写版本**。

**失败信号**：检查只有通过/不通过没有原因；出包不绑版本；blocker 被静默忽略；错误文案是堆栈或“操作失败”。

#### D. 回主线（2 分钟）

1. 编辑器点“主线” → 回四步工作流。
2. 确认当前项目、版本和刚采用的内容还在。
3. 走一遍“复原 → 适己 → 怎么做 → 加工包”的可见步骤，确认没有空白页、没有死按钮。
4. 如果中途返回，确认已经做的采用和检查结果没有丢。

## 验收判据

### 必须过

- 任何“预览”都不改版本；只有“采用/保存”改版本。
- 取消、Esc、撤销都能回到上一个可用状态。
- 修改后检查结果失效；重新检查必须针对当前版本。
- 不静默通过：没验证的承载、公差、cam lock 几何必须显示为警告/未覆盖。
- 每个错误都有下一步，不是只有“失败”。
- 主流程四步都能走通；返回后项目不丢。
- 浏览器 console 无未处理异常。
- 第一页加工包一页能回答：是什么、多少钱、几张板、下一步做什么。

### 应该过

- 本地交互反馈 < 200 ms；出包 < 10 s（不含打印机）。
- 拖拽手柄选中、旋转、取消的视觉反馈稳定。
- 状态在刷新后保留（采用后的版本、项目）。
- 关键按钮有 disabled 状态，不是点了没反应。
- 中文文案没有重复、没有内部字段名（`part_id`、`local_z` 之类）直接露给用户。
