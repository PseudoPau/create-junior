## 统一用词

| 用词 | 含义 | 不再使用 |
|---|---|---|
| 复原 / 适己 / 做法 / 出包 | 流程的四步 | 参考 / 尺寸 / 材料 / 资料；参考 / Module / 做法 |
| 加工包 | 第三个页面和最终交付物 | 制作包、设计包 |
| Module | 适己这一步里的个人身体数据与主要坐姿档案 | 作为步骤名 |
| 原版基线 | 复原得到、后续修改都参照的那一版 | — |
| 保型档案 | 一把椅子的特征、可调项及范围、边界 | — |
| 座板前后长度 | 原型字段 `seat_depth_mm` 的实际含义 | 有效坐深（尚未定义） |
