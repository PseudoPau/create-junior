## 配置

原型运行在会话模式，无需 API key。需要在线自动生成时，修改项目根目录 .env：

```dotenv
CREATE_JUNIOR_AI_PROVIDER=openai_compatible
CREATE_JUNIOR_AI_BASE_URL=https://你的服务地址/v1
CREATE_JUNIOR_AI_API_KEY=你的密钥
CREATE_JUNIOR_AI_MODEL=服务商实际提供的视觉模型名
```

重启：`uv run uvicorn app.main:app --host 127.0.0.1 --port 8000 --env-file .env`。模型需支持图片输入和所要求的 JSON 输出；配置齐全不等于调用已验证。
