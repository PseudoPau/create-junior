# 路线图与交接项

按 R1 → R1.3 → R2 → R3 推进。每轮以可验证的用户结果收尾，实现和验证分开记录，见 [迭代说明](iterations.md)。流程以 [交接稿 v2](design-handoff-v2.md) 为准。

## 已有原型基线

- 独立的本地 Web 工作台和项目存储。
- 参考、结构化候选、部件、连接、图纸和清单共用项目版本。
- 会话协作、在线适配器、本地原型和固定案例分别标注。
- CAFE CHAIR 会话辅助走查完成了设计采用、尺寸调整、加工方案、图纸预览和 ZIP 下载。

这份基线没有证明任意参考自动重建、在线模型端到端质量，或普通用户能独立完成。

## R1：页面与流程（待验收）

**用户结果**：知道从哪里开始、做到了哪一步、怎样继续和取得资料。

- 三个页面：开始制作、设计工作台、加工包。
- 案例和我的项目入口，可以继续已有项目。
- 区分当前设计与待采用的修改；生成、交接、失败各有提示。
- 加工包按采购、加工、装配组织，显示版本和检查范围。
- CAFE CHAIR 样例的 Module：三项身体数据加坐姿，座高、座宽、座板前后长度和靠背角的部件与孔位联动。

**完成条件**：在现有案例上走通新入口、继续项目、修改与采用、加工包和返回设计，并记录实际的浏览器走查。

R1 的流程逻辑已被 R1.3 取代：按公式逐项确认尺寸、逐个确认连接、步骤门槛，都在 R1.3 中改掉。

## R1.3：流程重排（待验收）

当前实现、已做验证及剩余边界见 [会话 Agent 实施记录](session-agent-iteration.md)。本轮采用会话协作 Agent 与简单平面斜切；旧计划中的未定项以此记录和实际实现为准。

**用户结果**：在样例椅上，什么都不改可以三步出包；想为自己调整时，只处理原椅子与自己不合的几项。

第一批不依赖待定规则，对应 [交接稿 v2 §5.1](design-handoff-v2.md)：

- 提交参考即生成，去掉中间页和第二次点击。
- 第一版模型不设“采用 / 不采用”，继续即建立原版基线。
- 取消连接逐个确认和步骤门槛，“保持原样”常驻。
- 出包按钮常驻并显示未解决项；爆炸图和开工总览移到加工包。

第二批需要先定 [交接稿 v2 §8](design-handoff-v2.md) 第 1–6 项，对应 §5.2 和 §5.3：

- 为样例椅写出保型档案：特征、可调项及范围、边界。
- 用“原值、适合范围、可调范围”的比较取代前端公式，适己改为差异列表。
- 冲突说明与改款分支；原版对比与恢复。
- 统一修改动作；模型标注直接编辑。

**完成条件**：[交接稿 v2 §7](design-handoff-v2.md) 的 A01–A08、A10、A11、A14、A15 在样例椅上通过，并记录实际的浏览器走查。座板不会再出现 400 × 215 mm 变成 655 × 448 mm 这类无提示的变形。

## R2：餐椅自主完成（计划中）

**用户结果**：不需要开发者导入 JSON，就能从有效参考得到自己的椅子，并按目标调整。

- 接入并实测一个在线视觉模型，记录有效输入的成功率和失败原因。
- AI 在复原时同时给出保型档案，不只是模型。
- 做法可修改：点选部件或连接，在可行的材料、板厚、连接、五金中选择，模型和清单同步。
- 覆盖链接不可读、缺尺度、服务失败、过期候选和重新打开项目的恢复路径。

**完成条件**：陌生用户能独立完成复原、适己和做法；固定案例和自动生成分别统计。建议以 5 位无 CAD 经验的用户试验、至少 4 位独立完成作为首轮目标，目前没有达成数据。

依赖：[交接稿 v2 §8](design-handoff-v2.md) 第 8、11 项，以及在线模型的选择。

## R3：加工包可交付（计划中）

**用户结果**：清楚该采购什么、交给加工者什么、怎样装配。

- 可打印的资料、可读的清单，零件与连接图编号一致。
- 按步骤展示部件、五金、工具、方向和装配顺序。
- 区分草稿、送审或询价资料、正式加工包。
- 由没有参与设计的加工者只看包、不读聊天和 JSON，判断加工准备是否完整。
- 用受控样件验证装配，记录实际问题，再调整支持范围。

**完成条件**：加工者能识别所需信息和剩余的核对项；模型、清单、图纸同版本；样件问题能追溯到设计并修正。下载成功不能代替实物验证。

## 需要负责人决定的事项

流程规则共 12 项，见 [交接稿 v2 §8](design-handoff-v2.md)，其中第 1–6 项决定 R1.3 第二批能否开工。另有：

- 默认加工路径，以及允许用户切换的方式。
- 在线模型的提供方、部署方式、费用和数据处理规则。
- 首发交付止于送审资料，还是包含专业复核的加工包。

首发家具已定为餐椅。不为未确认的能力承诺发布日期。社区、空间规划、供应商网络和专业建模工具在核心路径验证后再排期。
