## 一页看完

**产品**：用户带来一把喜欢的椅子，拿走一把适合自己、能交给加工店的同款。

**核心规则**：默认保持原椅子。只改它与使用者不合、而且这把椅子允许改的地方。

**流程**：一条基线，一种修改动作，一个出口。

| 步骤 | 用户在回答 | 系统给出 | 用户动作 |
|---|---|---|---|
| 1 复原 | 这是我要的那把椅子吗 | 提交参考即开始生成。第一版包含形状、真实尺寸、默认材料 / 板厚 / 连接，以及这把椅子的特征和可调范围 | 指出哪里不像，或直接继续 |
| 2 适己 | 它哪里不适合我 | 用户填一次身体数据和坐姿；系统拿原椅子和人比较，只列出不合适的项，每项带可调范围 | 每项选保持原样、采用建议或自己输入；超出范围进入改款分支 |
| 3 做法 | 我打算怎么做 | 沿用第一版自带的做法；只列出参考定不下来的选择和被第 2 步波及的连接 | 逐项选择，或主动点选部件修改 |
| 4 出包 | — | 出包按钮一直在；有未解决项时显示还差几项并能定位 | 生成加工包 |

**三条贯穿规则**

1. 修改只有一种动作：选中对象 → 输入或采纳建议 → 预览联动 → 采用或取消。Module 建议、点模型标注、对 AI 说，是它的三个入口。
2. 第 2、3 步是推荐顺序，不是门槛。什么都不改时，最短路径是提交参考 → 继续 → 生成加工包。
3. 没有“确认”这一步。没改的东西不需要确认；核对是出包按钮的条件。

**旧流程错在哪**（原稿的八阶段和现有原型）

- 保型规则没有出处：复原只产出模型，后面的“受原设计约束”无物可依。
- 适己方向反了：用身体数据算出一把标准椅再套到模型上，全程不读原椅子。座板从 400 × 215 mm 变成 655 × 448 mm 就出自这里。
- “一次一个决定”做成了“一次一个确认”：从提交参考到出包约 18 次推进点击，多数在确认用户没改过的东西。
- 做法来得太晚：没有材料、板厚和连接，第一版不是一把能做的椅子；板厚一改，前面定好的尺寸要重算。

## 1. 已定的约束

这些来自产品负责人的明确要求，设计时不再重新讨论。

- **首发家具**：餐椅 / 普通坐姿椅。复杂度以石卷工坊风格的平直板件家具为准。
- **用户**：不需要懂 CAD、节点、孔轴或木工术语。
- **参考输入**：产品网页、图片、图纸和文字。给过的参考不再要求重填。
- **AI**：真正参与理解参考、生成可编辑三维结构、提出尺寸与做法修改。在线 AI、样例体验和本地演示必须能区分，演示不能冒充对参考的识别。
- **Module**：只要求身高、坐高、臀宽三项，加一个主要坐姿（正坐、靠坐、斜靠、盘腿）。以模度人示意作为输入界面，数据存为个人档案。
- **工作台**：三维模型是画面和操作的中心。辅助信息只占一个操作区，不做左中右三栏。
- **尺寸编辑**：可以在模型标注上直接输入。
- **节奏**：一次只处理一个有意义的决定。
- **输出**：可编辑模型、PDF/SVG 图纸、加工包（采购单、下料清单、五金清单）。
- **形态**：纯 Web，可使用开源几何库。编辑器具备选择、旋转、尺寸输入、部件树、测量、撤销 / 重做、视角控制。
- **制作基线**：标准板材、平直板件、简单直角切割。更复杂的工艺要明确是否支持，见 §8 第 1 项。
- **检查范围**：模型与加工资料一致，不等于承载、稳定性、舒适性已验证。在相关决定处说一次，不每步重复。
- **本轮不做**：多品类、曲面与软包、完整 CAD、复杂工艺、投放与定价。

## 2. 四步细则

### 2.1 复原：这是我要的那把椅子吗

这一步的产出是**原版基线**。后面所有修改都以它为参照，随时可以对比和恢复。基线包含四样东西：

| 内容 | 说明 |
|---|---|
| 形 | 部件、外轮廓、关键比例、接合关系 |
| 尺寸 | 来自参考的真实尺寸；没有依据的标为估算 |
| 做法 | 材料、板厚、连接、五金的默认方案，来自参考网页、图纸和 AI 分析 |
| 保型档案 | 特征（必须保留）、可调项及范围（可以为人调整）、边界（越过即改款） |

保型档案针对这一把椅子，不是通用尺寸表，也不能用“改动不超过统一百分比”代替。识别不确定时，把判断交给用户。

交互：

1. 首页提交参考即开始生成，直接进入工作台。没有“参考已收到”中间页，也没有第二次点击。
2. 主画面显示真实处理状态，可以取消。链接读不到或缺少尺度时，在同一处提出一项具体的补充。
3. 第一版出现后，画面给出模型、参考对照和三到五条“这把椅子的特征”。材料和不确定的假设按需展开。
4. 两个动作：**继续**（以这一版为基线，进入适己）和**哪里不像**（指出部位或用文字描述，AI 修改后仍停在这一步）。不设单独的“采用 / 不采用”。

尺度：至少需要一个真实尺寸作锚点，例如总高或座高。没有时，模型标为比例估算，可以继续查看和修改，但不生成下料尺寸。

### 2.2 适己：它哪里不适合我

**输入一次。** 用户在模度人示意上把参考数字改成自己的身高、坐高、臀宽，选一个主要坐姿。

- 示意上的数字是示例，不能当成用户数据保存，也不能称作柯布西耶的原始数值。
- cm 和 mm 都能直接输入并正确换算。
- 其余身体参数由系统估算并标明，不作为必填项。
- “不填，保持原样”始终可见。

**比较，不是计算。** 对每个可调项，系统比较三样东西：原值、这个人的适合范围、这把椅子的可调范围。

| 情况 | 处理 |
|---|---|
| 原值在适合范围内 | 不列出，计入“其余已合适” |
| 原值不合适，可调范围内够得着 | 列为一项建议，建议值取进入适合范围所需的最小改动 |
| 可调范围内够不着 | 列为冲突，见下文 |

每项建议在模型上显示原值、建议值、可调范围和一句依据，一次展示一项。三个选择：保持原样、采用建议、自己输入。用户不选就是保持原样，系统不替用户采用。

没有不合适的项时，直接告知原椅子的尺寸对这个人合适，并给出继续。

**身体数据各自对应什么**

| 输入 | 用来判断 | 说明 |
|---|---|---|
| 身高 | 座高 | 通过估算的小腿长度，标为估算 |
| 臀宽 | 座宽 | 加上坐姿需要的活动余量 |
| 坐高 | 靠背高度是否合适 | 现有原型用它估座深，没有依据，见 §8 第 4 项 |
| 主要坐姿 | 这把椅子的构造是否支持 | 见 §8 第 2 项 |

座板前后长度没有直接对应的输入，默认不建议修改，除非用户主动提出。

**冲突。** 适合范围落在可调范围之外时，在同一操作区说明具体冲突，给三个选择：

- 有限调整：改到可调范围的边界，并说明仍然存在的限制。
- 改款提案：单独一版，明说哪些特征会变。采用后成为新版本，原版基线保留。
- 改主要坐姿或补充信息，重新比较。

坐姿与构造不相容时，在选坐姿的那一刻就提示，不等比较完再报错。

**档案。** 身体数据保存后，再次进入时直接显示差异列表和档案摘要。修改身体数据会重新比较；已采用的修改保留，直到用户采用新的修改。

### 2.3 做法：我打算怎么做

第一版已经带着默认做法，所以这一步默认是“沿用”。只在三种情况下出现待处理项：

| 来源 | 例子 | 处理 |
|---|---|---|
| 参考定不下来 | 看不到的背面连接有两种可行做法 | 一次展示一个选择，说明外观、是否可拆、加工要求 |
| 被适己改动波及 | 座高改变后靠背连接的孔位 | 系统重算并重新检查；通过的直接沿用，失败或有多种做法时才成为待处理项 |
| 用户主动修改 | 想换板厚或连接方式 | 点选部件或接合处，在可行选项中选择 |

可编辑的内容：

| 对象 | 可改什么 | 要展示的影响 |
|---|---|---|
| 部件 / 材料 | 支持的材料、板厚 | 外观、尺寸、连接和采购变化 |
| 连接 | 当前构造下可实现的连接方式 | 是否可拆、可见外观、加工要求、关联零件 |
| 五金 | 该连接支持的规格和数量方案 | 适用板厚、孔位、采购变化 |

只列可行的选项。不可行的组合要解释原因并给出具体替代。采用后模型、孔位和清单同步变化，只有真正受影响的部分重新检查。

“由谁加工”（自己加工，或加工店制件后自己装配）保留为这一步的一个选择，因为它决定加工包的组织方式。

### 2.4 出包

出包按钮从第一版出现起就在。点击后按下面的分类处理：

| 类别 | 处理 |
|---|---|
| 真正阻塞 | 缺少必要尺寸、几何无效、连接不成立。定位到模型并给出修正路径，解决前不能出包 |
| 未做的决定 | 例如两种可行连接尚未选择。一次展示一个 |
| 非阻塞说明 | 折叠记录，可查看，不靠勾选推进 |
| 已采用且未受影响 | 直接沿用 |

没有待处理项时直接生成，成功后进入加工包页。核对围绕模型进行，不要求用户先读图纸。

加工包按三个问题组织，并提供可编辑的模型数据：

- **我买什么**：板材、五金和采购信息。
- **交给加工店什么**：零件编号、下料清单、PDF/SVG 图纸和加工说明。
- **我怎么装**：装配顺序、连接做法、对应五金和分解示意。

模型、图纸、采购和下料绑定同一版本。返回修改后，旧包保留版本标识，新设计需要重新生成；生成失败时保留设计并可重试。

## 3. 修改动作

尺寸、材料、连接的修改共用同一个动作。

| 用户动作 | 反馈 |
|---|---|
| 选中座板、部件或一项建议 | 只显示与当前选择有关的尺寸线 |
| 点击尺寸数字 | 原位置出现输入控件，焦点进入数值 |
| 输入数值、单位或简单算式 | 显示换算后的目标值和模型预览，例如 `42 cm`、`400+20 mm` |
| 输入合法且在范围内 | 预览关联部件的变化，不覆盖已保存版本 |
| Enter 或“下一个” | 采用。不再出现第二次确认 |
| Esc 或取消 | 恢复到修改前 |
| 超出保型或制造边界 | 在同一处说明影响并给出可行选择，不默默截断数值 |
| 输入为空或无法换算 | 保留输入内容并解释，不能当作 0 保存 |
| 撤销 / 重做 | 恢复整次关联修改，包括尺寸、部件和受影响的做法 |

界面上要能分清五个值：原值、当前已采用值、建议值、预览值、可调范围。概览只显示已采用值，建议不能覆盖用户的选择。

算式只支持简单的长度计算和换算，不需要通用表达式能力。

## 4. 工作台

- 模型不能因为面板而被压成缩略图或隐藏。约 800 px 的桌面窄窗口下仍然成立。
- 所有输入和操作在同一个操作区完成，不在侧栏、底部和弹窗之间迁移。现有原型以底部浮动面板为基线，形式可以优化。
- 操作区一次只展示当前对象、必要输入、一句依据和下一步。完成态比编辑态短。
- 面板的开合由用户控制，步骤推进和窗口变化不自动开合。
- 部件树、参考原图、版本、完整参数、详细检查按需打开。
- 内部节点图、原始 JSON、任务路由、错误堆栈不出现在普通用户界面。

“在模型中查看”的约定：保持整椅装配状态，高亮相关部件或接合处，必要时微调视角；说明留在原操作区；返回时恢复原来的选中状态和视角。爆炸图、全量分料和加工大样属于加工包，局部透明或剖切只在用户主动开启时出现。

## 6. 分支与恢复

| 情况 | 应该发生什么 |
|---|---|
| 网页无法读取 | 保留链接，说明读不到的部分，允许补图或用其他参考继续 |
| 参考缺少关键尺度 | 提出一项明确补充，或给出标明估算的版本；估算不生成下料尺寸 |
| AI 未配置、失败或超时 | 区分三种状态，可重试或取消，当前设计不丢 |
| 第一版与参考不符 | 同一画面对比，用户指出哪里不符后继续修改 |
| 主要坐姿不适合原构造 | 说明冲突，给出有限调整、改坐姿、改款三个选择 |
| 关联修改失败 | 保留修改前的模型，指出失败部位和可行操作 |
| 用户返回前一步 | 已填内容、当前版本和选择都保留，面板不无故收起 |
| 改板厚影响已有连接 | 只重新检查受影响部分，并解释原因 |
| 其他标签页修改了项目 | 提示版本变化，保留本地未提交的输入 |
| 刷新或重开项目 | 恢复已保存设计，区分已保存和未提交的编辑 |
| 窗口变窄或面板展开 | 模型仍可用，操作留在同一位置 |
| 加工包生成失败 | 保留设计，显示错误和重试入口 |

## 7. 验收场景

| 编号 | 操作 | 通过条件 |
|---|---|---|
| A01 | 提交参考 | 只输入一次，直接在工作台看到处理状态和第一版 |
| A02 | 什么都不改直接出包 | 提交参考 → 继续 → 生成加工包，中间没有其他必经步骤 |
| A03 | 对照参考看第一版 | 轮廓、部件和比例能对应；不确定处有标注；能看到这把椅子的特征 |
| A04 | 填三项身体数据和坐姿 | 能保存和修改；原椅子已合适的项不出现 |

| A06 | 输入明显改变原设计的尺寸 | 出现具体取舍或改款提案，不会无提示变形 |
| A07 | 在模型标注上修改、取消、撤销 | 预览、采用、取消语义清楚；撤销恢复整次关联修改 |

| A15 | 生成失败、几何失败、版本冲突 | 有原因和恢复动作，设计和输入不丢 |

## 8. 待定规则

每项附建议，决定权在产品负责人。

**流程前提**：定下来之前，§5.2 无法实施。

1. **斜切进不进 MVP。** 样例椅是斜靠背加座板后缘斜切，与“简单直角切割”的基线矛盾。建议：把平面斜切列为 MVP 唯一支持的非直角工艺，其余仍不支持。
2. **四种坐姿实际承诺哪些。** 建议：四种都能选，由每把椅子的保型档案声明支持哪些；样例六板椅先承诺正坐和靠坐，斜靠和盘腿进入冲突分支。需要用样例验证。
3. **靠背角算适己项还是做法项。** 改它会牵动座板斜切面、孔轴和螺栓长度。建议：归入做法或改款，不作为适己的默认项。
4. **坐高的用途。** 建议：用于判断靠背高度是否合适。样例椅的联动规则目前没有靠背高度这一项，需要决定是加入可调项，还是只做提示。
5. **样例椅的保型边界。** 哪些关系必须保留、每个可调项的范围、何时算改款，都需要针对样例写出并验证。
6. **尺寸名称。** 原型的 `seat_depth_mm` 是座板前后长度，不是有效坐深。建议：界面统一叫“座板前后长度”，等定义了有效坐深的测量方法后再引入。

**不阻塞流程**

7. **载荷与使用环境。** 普通用户难以回答载荷，产品也不验证承载。建议：不再作为必答问题，使用环境默认室内并可修改，承载未验证的说明放在出包处。
8. **做法选项范围。** 首发哪些材料、板厚、连接和五金组合有足够的规则可供选择。
9. **PDF 交付方式。** 直接生成 PDF，还是先提供可打印页面。
10. **小屏下限。** 桌面窄窗口必须可用；手机是否提供同等编辑能力未定。
11. **AI 复原的验收标准。** 首发参考集、形态与尺寸的准确性标准、允许的补充信息和失败恢复方式。
12. **个人档案的保存范围。** 是否跨项目复用、是否支持多人、如何覆盖旧档案。
